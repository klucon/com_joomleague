# Project administration status

## Scope

The administrator dashboard distinguishes global entity management from workflows that require project context. Rounds and matches are implemented, but they are intentionally reached through a project stage and round rather than exposed as ambiguous global lists.

## Project panel

The project workspace reports canonical aggregate counts for:

- project entries;
- stages;
- rounds;
- matches.

Counts are loaded from their canonical project-owned tables and displayed through en-GB language constants. No sport code, custom CSS or custom JavaScript is used.

Standings remain explicitly planned. The bundled profiles do not yet provide one complete calculation contract for team tables, nested-score leagues, races and classifications. A football-only implementation must not be presented as universal standings.
