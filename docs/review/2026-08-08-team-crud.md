# Team administration CRUD

Date: 2026-08-08

## Implemented

- Replaced the Teams placeholder with Joomla administrator list and edit views.
- Added search, club and publication filters, ordering and pagination.
- Added create, edit, publish, unpublish, check-in and delete actions.
- Added optional club ownership using the canonical nullable `club_id` foreign key.
- Added full, middle and short team names, website and external migration identifier.
- Added a canonical team logo while preserving `picture` as a separate team photograph.
- Added Media, Description and Publishing tabs alongside Details.
- Added project participation counts to the list.
- Prevented deletion while project entries reference the team.
- Marked Teams as available in the central administration domain catalogue.
- Kept mobile lists within the viewport using Joomla/Bootstrap responsive utilities and no custom CSS.

## Validation

- Team name is required and Joomla generates an alias when omitted.
- Empty optional values, media paths and `club_id = 0` are normalized to `NULL`.
- UUID generation and audit metadata follow the same contract as other canonical entities.
- All visible text and field descriptions use the bundled `en-GB` language file.

## Verification

- PHP syntax, XML and architecture checks pass.
- The architecture suite reports 15 profiles, 17 tables for both database drivers and 1127 `en-GB` keys.
- The package installs on Joomla 6.2 test instances backed by MariaDB and PostgreSQL.
- Playwright validates the team list and its four-tab editor on desktop and mobile.
- A CRUD smoke test creates, lists and deletes a temporary independent team through Joomla on both database drivers.
- Schema update `6.2.0-20260808.4` adds `team.logo` without changing `team.picture`.
