# JoomLeague 6.1.0-alpha-153

JoomLeague 6.1.0-alpha-153 is a public alpha update for Joomla 6 focused on administrator workflows, match reporting, structured data, mobile table usability, language package delivery and release distribution metadata.

## Highlights

- Added administrator language package management with translation status, download, update and remove actions.
- Published optional Joomla language packages separately from the English-only main package.
- Added release pages, checksums, release JSON, update XML and language package manifests for KLUCON download/update endpoints.
- Improved project setup workflows with AJAX assignment for project teams, players and staff.
- Improved administrator match data screens, toolbar navigation and compact match action columns.
- Reworked match reports with compact lineups, referees, timed events, running goal scores and linked people/team output.
- Added text-only external people for opponent match events and text-only referees for lower-league reporting.
- Expanded Schema.org structured data across public views, with detailed SportsEvent data for match reports.
- Kept frontend match, results and schedule output as real scrollable tables on mobile.
- Improved ranking display, favourite-team row highlighting, ranking curve visuals and chronological round ordering.

## Compatibility

- Joomla: 6.x
- PHP: 8.3 or newer
- Status: public alpha
