# Club administration CRUD

Date: 2026-08-08

## Implemented

- Replaced the Clubs placeholder with Joomla administrator list and edit views.
- Added search, ordering, pagination, publish, unpublish, check-in and delete actions.
- Added club identity, website, external identifier and lifecycle date fields.
- Added one canonical club logo in the Media tab.
- Added a full-width description editor with its label on a separate row.
- Added UUID and audit-field handling consistent with competitions and seasons.
- Prevented deletion while teams reference the club.
- Marked Clubs as available in the central administration domain catalogue.
- Kept the list responsive using Joomla/Bootstrap utility classes and no custom CSS.

## Validation

- Club name is required and aliases are generated through Joomla.
- Country codes are normalized to uppercase and accept two to eight letters.
- Empty optional values and lifecycle dates are normalized to `NULL`.
- Dissolved date cannot precede founded date.
- All visible administrator text uses `en-GB` language keys.

## Description layout rule

Description fields in season, competition, project and club editors now follow one rule: the label occupies its own row and the editor is rendered below it at the full available width. Future administrator forms must use the same structure.

## Verification

- PHP syntax and XML validation pass.
- The architecture suite passes with 15 profiles, 17 tables for both database drivers and 1098 `en-GB` keys.
- The package installs on the Joomla 6.2 MariaDB and PostgreSQL test instances.
- Playwright verifies the club list and editor on desktop and mobile without document-level horizontal overflow.
- A Playwright CRUD smoke test creates, lists and deletes a temporary club through Joomla on both MariaDB and PostgreSQL.
- Schema update `6.2.0-20260808.4` adds the same nullable `logo` field on both database drivers.
